# 🚚 Transportation Problem Optimizer

A full-stack web application for solving transportation problems using Linear Programming methods.

## 📋 Features

- Four solution methods: North-West Corner, Least Cost, Vogel's Approximation, Exact LP
- Real-time comparison and visualization
- Interactive web interface
- Docker containerization
- PostgreSQL database

## 🛠️ Technologies

- **Frontend**: React.js, Chart.js
- **Backend**: Python Flask, PuLP
- **Database**: PostgreSQL
- **Deployment**: Docker

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/transportation-optimizer.git
cd transportation-optimizer

# Start with Docker
docker-compose up -d

# Access the application
# Frontend: http://localhost:3000
# Backend API: http://localhost:5000
